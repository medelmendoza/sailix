# Sailix (React Native) — `mobile/`

Independent React Native + TypeScript rebuild of the Sailix crew portal. The Flutter app (`../sailix`) is a **read-only behavioural reference**; no Flutter/Dart code is reused.

## Status

M0 foundation and **M5 app shell** are implemented and tested at JS level (114 tests, typecheck, lint, generated-API drift check, `expo export` for iOS and Android). **Not yet run on a simulator or device.** Tala course/content screens are blocked on the M3 gateway. Details: [`../docs/13-TALA-MVP-SCOPE-AND-ROADMAP.md`](../docs/13-TALA-MVP-SCOPE-AND-ROADMAP.md) §14.

## Stack

Expo SDK 57 (development builds + prebuild, **not Expo Go**) · React Native 0.86 · TypeScript (strict) · React Navigation 7 · TanStack Query · Zustand · Axios · zod · react-hook-form · Jest + React Native Testing Library. Rationale: [`docs/REACT-NATIVE-PLATFORM-DECISION.md`](../docs/reference/sailix-spec/REACT-NATIVE-PLATFORM-DECISION.md).

## Setup

```bash
npm install
cp .env.example .env.local   # no secrets; see below
```

Requires Node 22+, Xcode (iOS) / Android Studio (Android).

```bash
npm run ios        # expo run:ios  (builds a dev client; generates ios/)
npm run android    # expo run:android
npm start          # Metro for an installed dev client
```

`ios/` and `android/` are generated by `expo prebuild` and git-ignored; native config lives in `app.config.ts`.

## Quality gates

```bash
npm run validate            # typecheck + lint + tests
npm run gen:api:check       # generated types match ../contracts/openapi.yaml
npx expo-doctor
```

## Environment

Configured through `app.config.ts` → `extra` (values from the shell / EAS profile, see `.env.example` and `eas.json`): `APP_ENV`, `API_BASE_URL`, `API_PREFIX`, `PRIVACY_URL`. Staging/production builds require an `https://` API address. Everything in the app bundle is public — **never put secrets here**.

`src/app` (navigation, providers, config) · `src/components` · `src/features/*` · `src/services/{api,storage}` · `src/store` · `src/models` · `src/schemas` · `src/utils` · `src/constants`. Layering and rules: `../docs/reference/sailix-spec/14-REACT-NATIVE-ARCHITECTURE.md`.

## Design and demo mode
Visual language, tokens and the accessibility rules are in `../docs/07-MOBILE-ARCHITECTURE.md` §7 (`src/constants/theme.ts`; a test enforces WCAG AA contrast). To review the screens with sample data and an automatic tour (no backend, no sign-in):
```bash
DEMO_MODE=1 npx expo run:ios --configuration Release      # or: DEMO_MODE=1 xcodebuild … (see docs)
```
Demo mode is a build-time switch that is ignored for production builds.
