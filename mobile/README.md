# Sailix (React Native) — `mobile/`

Independent React Native + TypeScript rebuild of the Sailix crew portal. The Flutter app (`../sailix`) is a **read-only behavioural reference**; no Flutter/Dart code is reused.

## Stack

Expo SDK 57 (development builds + prebuild, **not Expo Go**) · React Native 0.86 · TypeScript (strict) · React Navigation 7 · TanStack Query · Zustand · Axios · zod · react-hook-form · Jest + React Native Testing Library. Rationale: [`docs/REACT-NATIVE-PLATFORM-DECISION.md`](../docs/reference/sailix-spec/REACT-NATIVE-PLATFORM-DECISION.md).

## Setup

```bash
npm install
cp .env.example .env.local   # no secrets; see below
```

Requires Node 22+, Xcode (iOS) / Android Studio (Android).

```bash
npm run ios        # expo run:ios  (builds a dev client; generates ios/)
npm run android    # expo run:android
npm start          # Metro for an installed dev client
```

`ios/` and `android/` are generated by `expo prebuild` and git-ignored; native config lives in `app.config.ts`.

## Quality gates

```bash
npm run typecheck && npm run lint && npm test     # or: npm run validate
npx expo-doctor
```

## Environment

Configured through `app.config.ts` → `extra` (values from the shell / EAS profile, see `.env.example` and `eas.json`): `APP_ENV`, `API_BASE_URL`, `API_PREFIX`, `PRIVACY_URL`, `SERVICES_ENABLED`. Everything in the app bundle is public — **never put secrets here**.

## Layout

`src/app` (navigation, providers, config) · `src/components` · `src/features/*` · `src/services/{api,storage}` · `src/store` · `src/models` · `src/schemas` · `src/utils` · `src/constants`. Layering and rules: `../docs/reference/sailix-spec/14-REACT-NATIVE-ARCHITECTURE.md`.
